❓ Guide d'utilisation Wake-On-LAN

📚 Qu'est-ce que Wake-On-LAN ?

Wake-On-LAN (WOL) est une norme informatique qui permet d'allumer ou de réveiller un ordinateur à distance en envoyant un paquet réseau spécial appelé "paquet magique". Ce paquet contient l'adresse MAC de la carte réseau de l'ordinateur cible.

Le paquet magique est composé de 6 octets de 0xFF suivis de 16 répétitions de l'adresse MAC (48 bits) de l'ordinateur cible, pour un total de 102 octets.

⚙️ Configuration du BIOS

Pour activer Wake-On-LAN, vous devez d'abord l'activer dans le BIOS de votre ordinateur :

  1. Redémarrez votre ordinateur et accédez au BIOS (généralement en appuyant sur F2, F10, DEL ou ESC au démarrage)
  2. Cherchez les options liées à l'alimentation (Power Management, Advanced Settings)
  3. Activez les options suivantes :
    • Wake-On-LAN ou PME Event Wake Up
    • Power On By PCI-E/PCI (pour certains BIOS)
    • Wake on Magic Packet
  4. Sauvegardez les modifications et redémarrez

🖥️ Configuration du système d'exploitation

Windows :

  1. Ouvrez le Gestionnaire de périphériques
  2. Développez Cartes réseau
  3. Clic droit sur votre carte réseau → Propriétés
  4. Onglet Gestion de l'alimentation :
    • ✓ Autoriser ce périphérique à sortir l'ordinateur du mode veille
    • ✓ Autoriser seulement un paquet magique à sortir l'ordinateur du mode veille
  5. Onglet Avancé :
    • Activez Wake on Magic Packet
    • Activez Wake on pattern match (optionnel)

Linux :

# Installer ethtool
sudo apt install ethtool

# Vérifier si WOL est supporté
sudo ethtool eth0 | grep Wake-on

# Activer WOL (g = Magic Packet)
sudo ethtool -s eth0 wol g

# Pour rendre permanent, créer un script au démarrage
echo '#!/bin/sh' | sudo tee /etc/network/if-up.d/wol
echo 'ethtool -s eth0 wol g' | sudo tee -a /etc/network/if-up.d/wol
sudo chmod +x /etc/network/if-up.d/wol

macOS :

  1. Ouvrez Préférences Système → Économiseur d'énergie
  2. Cochez Réveiller pour l'accès réseau Wi-Fi ou Wake for network access

🔍 Comment trouver l'adresse MAC ?

Windows :

ipconfig /all

Cherchez "Adresse physique" dans les informations de votre carte réseau

Linux :

ip link show
# ou
ifconfig

macOS :

ifconfig | grep ether

🌐 Quelle adresse IP utiliser ?

En réseau local (LAN) :

  • Broadcast : 255.255.255.255 (recommandé pour le réseau local)
  • IP locale : 192.168.x.x ou 10.x.x.x (si vous connaissez l'IP fixe)

À distance (via Internet) :

  • IP externe : L'adresse IP publique de votre box/routeur
  • Configuration requise :
    • Port forwarding sur votre routeur (redirection du port UDP 7 ou 9)
    • IP publique fixe ou service DynDNS
# Exemple de configuration port forwarding :
Protocole : UDP
Port externe : 9
Port interne : 9
IP interne : 255.255.255.255 (broadcast) ou IP de la machine

🔌 Ports UDP utilisés

  • Port 7 : Port Echo (standard ancien)
  • Port 9 : Port Discard (standard recommandé)
  • Certains équipements acceptent d'autres ports (ex: 2304, 4000)

Recommandation : Utilisez le port 9 par défaut. Si cela ne fonctionne pas, essayez le port 7.

⚠️ Limitations et contraintes

Limitations réseau :

  • Wi-Fi : WOL peut ne pas fonctionner en Wi-Fi sur certains ordinateurs. Une connexion Ethernet est recommandée.
  • VPN : Les VPN peuvent bloquer les paquets WOL. Configurez votre VPN pour autoriser le broadcast UDP.
  • Firewall : Assurez-vous que votre pare-feu autorise le trafic UDP sur les ports 7 et 9.
  • Switch réseau : Certains switchs bon marché ne transmettent pas correctement les paquets magic.

Limitations matérielles :

  • La carte réseau doit supporter WOL (la plupart des cartes modernes le font)
  • L'ordinateur doit être connecté à l'alimentation électrique
  • Certains ordinateurs portables ne supportent pas WOL sur batterie
  • Le mode "Arrêt complet" (shutdown) est requis, pas l'hibernation profonde

Box Internet et NAT :

  • Pour un accès distant, vous devez configurer le port forwarding sur votre box/routeur
  • Certaines box (4G/5G) ne permettent pas le port forwarding
  • Le CGNAT (Carrier-Grade NAT) peut empêcher WOL distant
  • Solution alternative : VPN personnel (WireGuard, OpenVPN) vers votre réseau local

🔒 Sécurité et recommandations

Bonnes pratiques :

  • ✓ Utilisez un mot de passe fort pour votre compte WOL Site
  • ✓ Ne partagez pas vos identifiants
  • ✓ Limitez l'accès au port forwarding uniquement aux ports nécessaires
  • ✓ Utilisez un VPN pour plus de sécurité lors de l'accès distant
  • ✓ Mettez à jour régulièrement le firmware de votre routeur
  • ✓ Activez le firewall sur votre routeur et vos ordinateurs

Risques potentiels :

  • ⚠️ Un paquet WOL peut être envoyé par n'importe qui connaissant votre adresse MAC
  • ⚠️ L'adresse MAC n'est PAS une information secrète (visible sur le réseau local)
  • ⚠️ Le port forwarding expose votre réseau : soyez prudent
  • ⚠️ Certains routeurs ont des failles de sécurité : maintenez-les à jour

Solutions sécurisées :

  1. VPN personnel : Installez un serveur VPN (WireGuard) sur votre réseau local et utilisez WOL via le VPN
  2. Authentification à deux facteurs : Utilisez des applications qui requièrent une authentification
  3. Whitelist IP : Configurez votre routeur pour n'accepter WOL que depuis certaines IP

🛠️ Dépannage

WOL ne fonctionne pas en local :

  • Vérifiez que WOL est activé dans le BIOS
  • Vérifiez les paramètres de la carte réseau (Windows)
  • Testez avec les ports 7 et 9
  • Essayez avec l'IP de broadcast (255.255.255.255)
  • Redémarrez complètement l'ordinateur (pas de mise en veille prolongée)

WOL ne fonctionne pas à distance :

  • Vérifiez la configuration du port forwarding
  • Testez avec votre IP publique
  • Vérifiez que votre FAI ne bloque pas les ports UDP
  • Essayez d'utiliser un VPN

Tests de diagnostic :

# Windows : Tester avec PowerShell
Test-NetConnection -ComputerName [IP] -Port [PORT]

# Linux : Envoyer un paquet WOL manuel
wakeonlan AA:BB:CC:DD:EE:FF
